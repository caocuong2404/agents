# Triage labels

Map canonical skill roles to these GitHub label names.

| Canonical role  | Repository label | Meaning                                    |
| --------------- | ---------------- | ------------------------------------------ |
| needs-triage    | needs-triage     | Maintainer needs to evaluate this issue.   |
| needs-info      | needs-info       | Waiting for information needed to proceed. |
| ready-for-agent | ready-for-agent  | Fully specified and ready for an agent.    |
| ready-for-human | ready-for-human  | Requires human implementation.             |
| wontfix         | wontfix          | Will not be actioned.                      |

Use the repository-label column when a skill requests a triage role.
